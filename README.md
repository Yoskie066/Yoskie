# 🎨 Einon Cris O. Alcantara — Portfolio Website

A modern, dark-themed developer portfolio built with **Next.js**, **TypeScript**, and **Tailwind CSS** — showcasing my journey as a Full-Stack Web Developer.

---

## 📌 About

This portfolio is a single-page application that presents my professional profile in a sleek, dark-themed interface. It features a typewriter hero section, an animated about card, service offerings, categorized technical skills, a vertical experience timeline, a carousel of featured projects, and multiple contact channels.

Motion-first design — powered by Framer Motion for entrance animations, scroll-triggered reveals, and hover interactions.

---

## 🚀 Features

### 🏠 Hero Section
- Animated typewriter effect on the job title
- Profile image with glowing circular frame
- CV Resume download button
- Projects scroll link button

### 👤 About Me
- Glowing animated border on the profile card
- Three-paragraph introduction (background, experience, career goals)

### 🛠️ Services
- Six service cards: Frontend Development, Backend Development, API Integration, Deployment & Hosting, UI/UX Design, Full-Stack Development
- Hover lift effect with animated border glow

### 💻 Technical Skills
- Categorized skill cards: Frontend, UI & Styling, Backend, Database & ORM, Tools & Deployment
- Official brand icons with correct colors
- Hover scale animation

### 📅 Experience Timeline
- Vertical timeline with icon nodes
- Five milestone entries (2022–2026): Internship, Backend Developer, Bootcamp, Freelance Developer, Personal Projects

### 🎯 Featured Projects
- Auto-playing carousel with manual navigation
- Five featured projects: Careerly, File Tracker, Waste Track, SixOneCafe, MindFul
- Slide indicators, prev/next controls, GitHub and Live Demo buttons

### 📬 Contact
- Four channels: Gmail, LinkedIn, GitHub, GitLab
- Hover animations on each contact button

## 🎨 Design Philosophy

- **Dark Theme** — Black background with subtle white/gray accents
- **Motion-First** — Every section animates in with Framer Motion
